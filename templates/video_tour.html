Free Deployment Instructions Zero Cost
Option A: Render (Recommended)
  1. Push your project to GitHub (git push origin main).
  2. Go to render.com → New Web Service.
  3. Connect your repo. Build: pip install -r requirements.txt.
  4. Start Command: gunicorn app:app.
  5. Select Free Plan and click Create!
Option B: PythonAnywhere (Forever Free)
  1. Sign up at pythonanywhere.com.
  2. Clone repo into your bash console.
  3. Go to Web Tab → Add New Web App (Flask, Python 3.11).
  4. Point the WSGI file to your app.py and click Reload.
  5. Your app is live forever at https://username.pythonanywhere.com.
